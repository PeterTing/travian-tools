## 1. 產品概述

### 1.1 背景

Travian: Legends 是一款複雜的網頁即時策略遊戲，玩家需要管理多個村莊、訓練軍隊、進行外交與戰爭。遊戲涉及大量的數值計算、資源管理和戰略決策，目前市場上缺乏全面的中文輔助工具。

### 1.2 產品願景

建立一個全方位的 Travian: Legends 智能助手，整合完整數據庫、智能計算器、AI 策略建議引擎與自動化執行能力。

### 1.3 目標用戶

| 用戶類型 | 描述 | 主要需求 |
|----------|------|----------|
| 新手玩家 | 剛接觸遊戲 | 學習機制、避免錯誤 |
| 活躍玩家 | 每天遊玩 2-4 小時 | 優化決策、節省時間 |
| 聯盟領導 | 管理聯盟團隊 | 協調作戰、數據分析 |

### 1.4 核心價值

| 用戶痛點 | 解決方案 |
|----------|----------|
| 數值計算複雜易錯 | 自動化計算器 |
| 不知道該優先做什麼 | AI 策略建議 |
| 手動追蹤遊戲狀態耗時 | 自動抓取數據 |
| 重複性操作繁瑣 | 半自動執行 |
| 缺乏中文資源 | 完整中文化 |

## 2. 功能需求

### F1. 遊戲數據庫系統 (Epic 1)

#### F1.1 建築數據查詢

**描述**: 提供所有建築 1-20 級完整數據查詢功能

**用戶故事**: 作為 Travian 玩家，我希望能查詢任意建築的各等級資訊，以便規劃建築升級順序和資源準備

**驗收標準**:
- [ ] 可查詢所有 40+ 種建築的 1-20 級數據
- [ ] 數據包含：成本（木/磚/鐵/糧）、建造時間、效果、前置需求
- [ ] 支援中英文建築名稱查詢
- [ ] 回應時間 < 200ms
- [ ] 數據與遊戲實際誤差 < 1%

**建築分類**:
- 資源類：伐木場、黏土坑、鐵礦場、農田
- 資源加成：鋸木廠、磚塊廠、鑄造廠、麵粉廠、麵包房
- 儲存：倉庫、糧倉、大倉庫、大糧倉、藏匿處
- 軍事類：兵營、馬廄、工坊、大兵營、大馬廄
- 強化：鐵匠鋪、防具工坊
- 防禦：城牆（各族不同）、陷阱工坊
- 基礎設施：本部、皇宮、行宮、大使館、市場、貿易所、市政廳
- 研發：研究院

#### F1.2 兵種數據查詢

**描述**: 提供所有種族兵種完整數據查詢與比較功能

**用戶故事**: 作為 Travian 玩家，我希望能查詢所有種族的兵種數據，以便選擇最適合的兵種進行訓練

**驗收標準**:
- [ ] 可查詢 7 個種族、約 70 種兵種數據
- [ ] 數據包含：攻防值、速度、成本、糧耗、訓練時間
- [ ] 支援兵種比較功能
- [ ] 顯示性價比計算（攻擊力/成本、防禦力/糧耗等）

**支援種族**:
| 種族 | 英文 | 特色 |
|------|------|------|
| 羅馬 | Romans | 同時建造、強力部隊、適合新手 |
| 高盧 | Gauls | 最快部隊、強防禦、雙倍藏匿 |
| 條頓 | Teutons | 便宜部隊、掠奪加成 +33% |
| 匈奴 | Huns | 強力騎兵、額外開村 |
| 埃及 | Egyptians | 經濟加成、防禦型 |
| 維京 | Vikings | 強大步兵、快速船隻 |
| 斯巴達 | Spartans | 強力單位、醫療所恢復 60% |

> **注意**: 種族數量會隨遊戲版本更新，系統需設計彈性架構支援新種族。

**驗收標準**:

#### F2.7 征服計算器

**描述**: 計算征服村莊所需波數、成本與慶典情境

### F3. AI 策略建議系統 (Epic 3)

#### F3.1 遊戲階段判斷

**描述**: 根據用戶狀態自動判斷遊戲階段

**階段定義**（與 `docs/knowledge/travian-mechanics.md` 的 Game Phases 對齊）：

| 階段 | 天數 | 村莊數 | 策略重點 |
|------|------|--------|----------|
| 保護期 | Day 1-3 | 1 | 新手保護、完成任務、英雄冒險搶資源 |
| 早期 | Day 1-45 | 1-4 | 快速開村、確立首都、控制象限、微農場 |
| 中期 | Day 45-90 | 4-6 | 第一波 ops 發動、兵種生產、神器前準備 |
| 後期 | Day 90 起 | 6-10+ | 神器爭奪、大規模戰役 |
| 終局/WW | Day 150 起 | 8-12+ | 全聯盟 WW 協作、持續生產防禦兵 |

**驗收標準**:
- [ ] 根據天數、村莊數、人口判斷階段
- [ ] 提供該階段標準目標
- [ ] 評估玩家進度（領先/正常/落後）

### F5. 半自動執行系統 (Epic 5)

> ⚠️ **重要說明**: 此功能涉及遊戲自動化，可能違反 Travian 使用條款。所有自動化操作均需使用者確認，並由使用者自行承擔風險。

#### F5.0 技術架構

**瀏覽器自動化方案**: Nodriver (Python)

選型理由：

- 繞過 CDP 協議偵測，反偵測能力最強
- Python 原生，與後端技術棧一致
- 活躍維護中
- 原生 asyncio 支援

技術文件參考: [BROWSER_AUTOMATION_RESEARCH.md](tech/BROWSER_AUTOMATION_RESEARCH.md)

---

- 支援官方 Travian: Legends

## 7. 技術實作參考

> ⚠️ **重要說明**: 本章節提供開發團隊實作時所需的計算公式與技術細節。完整數據結構、API 設計與詳細規格請參閱 [PROJECT-REQUIREMENTS.md](PROJECT-REQUIREMENTS.md)。

### 7.1 核心計算公式

#### 7.1.1 建築成本計算

```text
建築成本 = 基礎成本 × (成長係數 ^ (等級-1))
總成本 = Σ(各等級成本)
```

**範例**：兵營從 Lv10 升到 Lv15 的計算

- 需計算 Lv10→11, Lv11→12, Lv12→13, Lv13→14, Lv14→15 各級成本
- 加總即為總成本

#### 7.1.2 建造時間計算

```text
實際時間 = 基礎時間 × (時間係數 ^ (等級-1)) ÷ (1 + 本部等級 × 0.05) ÷ 伺服器倍率 ÷ 金幣加成
即時完成金幣 = floor(實際時間秒數 / 3600) + 1
```

**本部加成效果**：

| 本部等級 | 時間減少比例 |
| -------- | ------------ |
| Lv1      | -5%          |
| Lv10     | -50%         |
| Lv20     | -100%（減半）|

#### 7.1.3 資源田 ROI 計算

```text
產量增加 = 新等級產量 - 當前等級產量
回本時間(小時) = 升級總成本 ÷ 產量增加
ROI(30天) = (產量增加 × 24 × 30) ÷ 升級成本
```

**綠洲與建築加成疊加規則**：

```text
最終產量 = 基礎產量 × (1 + 綠洲加成) × (1 + 建築加成) × (1 + Plus加成) × (1 + 神器加成)
```

加成來源：

- 綠洲：+25% 或 +50%（最多可佔領 3 個綠洲）
- 鋸木廠/磚塊廠/鑄造廠：最高 +25%
- 麵粉廠 + 麵包房：糧食最高 +50%
- Plus 帳號：+25%
- 神器：視類型而定

#### 7.1.4 部隊訓練時間計算

```text
單兵訓練時間 = 基礎時間 ÷ (1 + 建築等級 × 0.05) ÷ 伺服器倍率
總時間 = 單兵訓練時間 × 數量 ÷ 訓練佇列數
```

**訓練建築對應**：

- 兵營：步兵
- 馬廄：騎兵
- 工坊：攻城武器

#### 7.1.5 戰鬥計算基礎公式

```text
攻擊力 = Σ(各兵種攻擊力 × 數量)
防禦力 = Σ(各兵種防禦力 × 數量) × (1 + 城牆加成)
```

**城牆防禦加成（Lv20）**：

| 種族 | 城牆類型 | 最大加成 |
| ---- | -------- | -------- |
| 羅馬 | 城牆     | +80%     |
| 高盧 | 木柵欄   | +60%     |
| 條頓 | 土牆     | +70%     |
| 匈奴 | 帳篷     | +40%     |
| 埃及 | 石牆     | +70%     |

#### 7.1.6 座標距離計算

```text
距離(格) = sqrt((x2-x1)² + (y2-y1)²)
抵達時間(小時) = 距離 ÷ 兵種速度
```

#### 7.1.7 糧食平衡計算

```text
人口糧耗 = Σ(各建築人口)
部隊糧耗 = Σ(各兵種糧耗 × 數量)
總糧耗 = 人口糧耗 + 部隊糧耗
糧食結餘 = 糧食產量 - 總糧耗
```

#### 7.1.8 忠誠度計算（征服）

```text
每波降低忠誠 = 20-30（隨機）
基礎忠誠度 = 100%
忠誠上限 = 125%（需 Town Hall 大慶典開啟）
忠誠恢復 = 每小時 +1%
```

**征服波數估算**：

- 每波 chief/chieftain/senator/logades 降低 loyalty 20-30%（隨機）
- Residence 提供 2 個 chief slots；Palace 提供 3 個
- 單玩家 1 個 hammer 有 Palace 20 = 3 chiefs/波 → 約 4 波攻下未慶典目標
- 2 個 3-chief 村（Palace 20 + Residence 20，或 Palace 20 × 2）= 6 chiefs/波
  → 單人 solo chiefing 可能
- 聯合攻擊：多玩家 chief 合體一波即可攻下慶典後的 125% loyalty
- Tablet of Law hero 消耗品可即刻 +5% loyalty

完整細節見 [`knowledge/loyalty-and-conquest.md`](knowledge/loyalty-and-conquest.md)。
