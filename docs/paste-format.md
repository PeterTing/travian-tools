# 貼上文字格式（P0-05）

擴充上傳送 HTML；手機／電腦也可貼 **HTML**（遊戲全選複製）或下列 **純文字**。

三種入口（貼上、擴充、截圖 OCR）都進同一個「解析結果確認」畫面，確認後才存入。

## 集結點

```
來村軍團 (N)
來源村 搶奪|攻擊 目標村
(x|y)
士兵 …
到達
在 HH:MM:SS 時

來村的支援
友軍村 支援 我方村
(x|y)

出擊軍團
我方村 搶奪 目標
(x|y)

村內部隊
自軍
士兵 …
```

規則：

- 一筆搶奪只會算成來襲或出擊其中一種（依區塊／關鍵字）
- 「村內部隊」是駐軍，不會當成來襲增援
- 重貼時依「來源、標題、抵達那一秒」分組：前 min(N,M) 筆更新，多的新增，**永不自動刪除**

## 多村資源

```
村名  木  泥  鐵  糧
Hello Moto  15126  11208  10940  174862
```

## 擷取時間

- 手機貼上通常沒有日期：確認畫面上的「擷取時間」可改；接近午夜會提醒確認日期
- 擴充上傳會帶 `#servertime`
