# 貼上文字格式（P0-05）

擴充上傳送 HTML；手機／電腦也可貼 **HTML**（遊戲全選複製）或下列 **純文字**。

三種入口（貼上、擴充、截圖 OCR）都進同一個「解析結果確認」畫面，確認後才存入。

## 集結點

```
來村軍團 (N)
來源村 搶奪|攻擊 目標村
(x|y)
士兵 …
到達
在 HH:MM:SS 時

來村的支援
友軍村 支援 我方村
(x|y)

出擊軍團
我方村 搶奪 目標
(x|y)

村內部隊
自軍
士兵 …
```

規則：

- 一筆搶奪只會算成來襲或出擊其中一種（依區塊／關鍵字）
- 「村內部隊」是駐軍，不會當成來襲增援
- 重貼時依「來源、標題、抵達那一秒」分組：前 min(N,M) 筆更新，多的新增，**永不自動刪除**

## 多村資源

```
村名  木  泥  鐵  糧
Hello Moto  15126  11208  10940  174862
```

## 擷取時間

- 手機貼上通常沒有日期：確認畫面上的「擷取時間」可改；接近午夜會提醒確認日期
- 擴充上傳會帶 `#servertime`


## 村莊總覽（dorf1）

擴充／貼 HTML 最準。純文字（遊戲頁 Ctrl+A）亦可：

- 需含「每小時的產量」與木材／磚塊（或泥土）／鋼鐵（或鐵礦）／穀物（或農田）
- 會抽出：目前村莊名稱與座標、人口、資源存量、產量、部隊列、村莊列表
- 田地等級：若複製成 18 個數字（可連成一串），會拆開存入；拆不出來時仍可存資源／村莊，確認畫面會註明
- **沒有解析到可存欄位時不會存入，也不會建立空白村莊**

## 村莊中心（dorf2）

擴充上傳送 HTML；純文字通常拆不出建築 slot，會明確失敗並請改用 HTML／擴充。

解析後會帶：村莊名稱、座標、人口、是否首都、建築列表、村內部隊。確認畫面可選「村莊」對到帳號裡的村，再存入。

## 戰報

```
（遊戲戰報列表或單份戰報的文字／HTML）
```

擴充／HTML 較準。存入走確認後的戰報同步；純文字格式之後再細定。

## 軍隊統計

統計 → 部隊頁。確認後把各村 `villages_troops` 寫入 `location=total` 的部隊列。沒有可寫的村莊部隊時會失敗，不會假裝成功。
