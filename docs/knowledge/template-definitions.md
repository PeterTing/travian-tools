# Template Definitions: Expected Slots & Buildings

Every village template must explicitly define the ultimate target state of a village.
The precomputed orders generated by the simulator will map step-by-step from an empty village up to this predefined state.

## 1. Capital Village Template

**Purpose:** Heart of the empire. Resources go beyond level 10. Cannot be conquered. Highest defense scaling.

### Resource Fields

* **Woodcutter** (All slots): Target Lv. 20
* **Clay Pit** (All slots): Target Lv. 20
* **Iron Mine** (All slots): Target Lv. 20
* **Cropland** (All slots): Target Lv. 20

| Sawmill | 5 | 5 | Boosts wood |
