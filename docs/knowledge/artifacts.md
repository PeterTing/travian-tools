# Artifacts

Source: Travian Support — [Artefacts](https://support.travian.com/en/support/solutions/articles/7000060687-artefacts), [Artefact Effects](https://support.travian.com/en/support/solutions/articles/7000060572-artefact-effects), [Artefact Limitations](https://support.travian.com/en/support/solutions/articles/7000069907-artefact-limitations-how-artefact-activation-works), [Construction Plans](https://support.travian.com/en/support/solutions/articles/7000068050-construction-plans).

## Release Timing

- Artifacts are created by Natars around **Day 90** on standard x1 servers (scales with speed: Day 30 on x3, earlier on x10).
- Initial release places 8 artifact villages controlled by Natars. Each must be captured or its Treasury destroyed for the artifact to transfer.

## Artifact Sizes

| Size | Effect scope | Treasury slots required |
|------|--------------|------------------------|
| Small | Single village | 40–60 |
| Large (Greater) | All villages in the account | 60–80 |
| Unique | All villages + stronger multiplier | 80–120 |

The **Treasury** building holds artifacts. Treasury Lv 10 holds one artifact; Lv 20 holds multiple.

## Effect Categories

| Category | Small | Large | Unique |
|----------|-------|-------|--------|
| Architect (building durability) | +200% single village | +100% all villages | +300% account (Stonemason-equivalent) |
| Boots of Mercury (troop speed) | 2× speed one village | 1.5× all villages | 2× all villages |
| Eyes of the Oracle (scouting) | See enemy troops | See farther | Wider scout range |
| Trainer (barracks/stable speed) | 2× one village | 1.5× account | 2× all buildings |
| Fool's Artifact (random effect) | random single-village weekly | random account weekly | stronger random |
| Warrior (unit crop consumption) | –50% crop one village | –25% account | –50% account |
| Storage (warehouse/granary capacity) | 2× one village | 1.5× account | 2× account |
| Great Warehouse / Great Granary plan | unlocks Great WH/GR in capital | | |
| Wonder of the World plan | required to build WW | | |

## Construction Plans

Specific artifact type that unlocks the **World Wonder** building. Required in late game to start any WW.

## Acquisition

1. Scout Natar artifact village for defense.
2. Attack with rams + catapults (target **Treasury Lv 10 or 20**).
3. A successful attacking wave whose cats destroy the Treasury **transfers** the artifact to the attacker's Treasury in the origin village of the catapults.
4. If the attacker loses the battle, the artifact stays with the defender.

## Activation Rules

- Artifact must sit in a Treasury Lv 10+ to be active.
- A village activates **one artifact** at a time (version-dependent: some servers allow one per category).
- Artifacts cannot be traded. Transfer only via capture (Treasury destruction).
- Unique artifacts: **one of each type per server**.

## Strategic Implications

- Artifact hunt reshapes Day 90 gameplay — every active player will scout or assist in grabbing one.
- Defensive players: stack Treasury + Stonemason + anvil to hold Natar captures.
- Offensive players: need cats + rams + speed buff + cage (for wild animal defenders) for Natar raids.
- Fool's Artifact can disable building construction randomly — flag in AI advisor warnings.

## Artifact-Holding Village Profile (Travco Plus view)

When scouting an alliance member's artifact village, Travco exposes:

- Hero boots tier (does hero speed-up land ops?)
- Catapult throughput (Workshop level, Smithy level)
- Tournament Square level (long-range speed)
- Treasury size (artifact count / size capacity)
