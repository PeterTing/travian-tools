### P0-02 帳號、世界切換與村莊列表 🔄
- 驗收：一個使用者可以有多個遊戲帳號；資料按帳號和世界分開存；每個帳號有「時間顯示時區」設定；畫面照 P0 線框稿 v0.4；帳號管理頁列出停用的帳號（收在「已停用（n）」）並可以重新啟用，村莊頁和頂部切換只顯示啟用中的帳號，停用和重新啟用都不刪資料
- 第二段驗收（村莊列表，照線框 v0.4「村莊列表」）：
  - [x] 每列第一行是村莊名稱＋座標 (x|y)（負號用「−」），第二行是人口和每小時糧食淨產量；負的標紅；還沒上傳過村莊總覽的村莊，糧顯示「還沒有資料」，不當成 0
  - [x] 頂部提示「最舊的資料是 n 小時前貼上的。」：照**最舊的那個村莊**算。每個村莊的時間是它最後一次成功上傳村莊總覽或村莊中心的時間（上傳記錄 `sync_logs`；`GET /villages?account_id=` 每列的 `last_pasted_at`，清單的 `oldest_pasted_at`），從沒貼上過的村莊不算；不到 1 分鐘是「剛剛」、不到 1 小時用分鐘、再來是「昨天」「n 天前」；有村莊但從沒貼上過時說明是手動輸入的；沒有村莊時顯示空狀態，不顯示提示
  - [x] 提示分三種程度（照最舊資料的時間）：不到 6 小時中性（線框 `--bg` 底、`--line` 框、`--mut` 字）；6 到 24 小時黃（`--warn` 淺底）；超過 24 小時紅（`--err` 淺底、深紅字），並多一句「數字可能已經不準。」，不只靠顏色
  - [x] 每列平常不標時間；只有那個村莊的資料超過 24 小時，才在第二行最後加灰字（`--mut`）「昨天」或「n 天前」
  - [x] 更新的說法：提示和空狀態都寫「要更新請到遊戲的村莊總覽，按擴充上傳。」（P0-03、P0-05 做完後改回線框的寫法）
  - [x] 只顯示頂部選的那個帳號（只會是啟用中的）；別的使用者的村莊和最後貼上時間一律看不到，有測試
  - [x] 手機寬度可用；排序可選人口、糧、名稱；整列點進村莊詳情，編輯和刪除移到詳情頁
  - [x] 擴充讀村莊總覽的產量時保留負號（原本負的糧會變成正的）
  - [ ] 角色標籤：列上的位置留好，之後再做。用資料庫現有的那組角色，中文：hammer＝鎚子、anvil＝鐵砧、resource＝供糧、mixed＝混合、ww＝奇觀；首都不是角色（照遊戲資料顯示「首都」標籤，`is_capital`），資料庫的 `capital` 角色不在選項裡；「征服」這一版不做
- 進度：第一段在 [#5](https://github.com/PeterTing/travian-tools/pull/5)：每個帳號的時間顯示設定、世界（`game_worlds`，伺服器 UTC 時差可手動改）、每組帳號＋世界的村數、資料分開的測試、頂部帳號／世界切換、`/game-accounts/new` 新增頁（必填只有世界、部族、遊戲內名稱）、管理頁的「已停用（n）」與重新啟用；第二段在 [#7](https://github.com/PeterTing/travian-tools/pull/7)：村莊列表照線框改版（名稱＋座標、人口、糧食淨產量、照最舊村莊算的三種程度提示、超過 24 小時的村莊標幾天前、空狀態）；角色標籤還沒做

### P0-04 擴充重寫 ⬜（3 天）
- 驗收：
  - 只用 `activeTab`；不插入、不改動遊戲頁面；上傳時帶入 `#servertime`
  - 擴充沒有計時器、輪詢或自行發出的請求，背景程式只回應工具網站傳來的訊息。
  - popup 裡沒有任何輸入框
  - 沒登入時只顯示「在工具網站登入」（按鈕開新分頁到工具網站）
  - 交給擴充的登入憑證有到期時間，登出時要一起清掉（網站登出與擴充登出都要清）
  - 伺服器端可撤銷擴充憑證：每個使用者有 `extension_token_version`，只有擴充憑證帶這個版本；網站登出時 +1，之前發出的擴充憑證一律 401。網站自己的 access / refresh token 不受影響（其他裝置不會被登出；「登出所有裝置」不在範圍內）
  - 擴充憑證只能上傳（`scope=extension_upload`）：只有 popup 會呼叫的上傳 API 接受；其他 API 一律 403，包含帳號設定、換發擴充憑證、刷新 token
