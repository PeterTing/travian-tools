## API 整合

```typescript
// 取得遊戲帳號列表
GET /api/v1/game-accounts
Response: GameAccount[]

// 新增遊戲帳號
POST /api/v1/game-accounts
Request: GameAccountFormData
Response: GameAccount

// 更新遊戲帳號
PUT /api/v1/game-accounts/{id}
Request: Partial<GameAccountFormData>
Response: GameAccount

// 刪除遊戲帳號
DELETE /api/v1/game-accounts/{id}
Response: { success: true }

// 同步數據
POST /api/v1/game-accounts/{id}/sync
Response: { lastSync: Date; villageCount: number; population: number }
```
