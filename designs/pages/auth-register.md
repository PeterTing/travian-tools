## 元件規格

### RegisterForm

```typescript
interface RegisterFormProps {
  onSubmit: (data: RegisterData) => Promise<void>;
  isLoading: boolean;
  error: string | null;
}

interface RegisterData {
  name: string;
  email: string;
  password: string;
  confirmPassword: string;
  agreeToTerms: boolean;
}
```

### PasswordStrengthIndicator

```typescript
interface PasswordStrengthIndicatorProps {
  password: string;
}

// 強度等級: weak | medium | strong
```

## 表單驗證

| 欄位 | 驗證規則 | 錯誤訊息 |
|------|----------|----------|
| 使用者名稱 | 必填、2-50 字元 | "使用者名稱須為 2-50 字元" |
| Email | 必填、Email 格式、唯一 | "請輸入有效的 Email" / "此 Email 已被註冊" |
| 密碼 | 必填、最少 8 字元、含大小寫和數字 | "密碼須至少 8 字元，包含大小寫字母和數字" |
| 確認密碼 | 必填、與密碼相同 | "兩次密碼輸入不一致" |
| 同意條款 | 必須勾選 | "請同意服務條款" |

---

## 密碼強度規則

| 強度 | 條件 |
|------|------|
| 弱 | 僅滿足長度要求 |
| 中等 | 長度 + (大寫或小寫) + 數字 |
| 強 | 長度 + 大寫 + 小寫 + 數字 + 特殊字元 |

## API 整合

```typescript
POST /api/v1/auth/register
Request: {
  name: string;
  email: string;
  password: string;
}
Response: {
  user: {
    id: string;
    email: string;
    name: string;
  };
  message: "註冊成功，請查收驗證信"
}
```

---

## 流程

1. 用戶填寫註冊表單
2. 即時驗證各欄位
3. 點擊建立帳號
4. 發送 API 請求
5. 成功：顯示成功訊息，導向登入頁或直接登入
6. 失敗：顯示錯誤訊息（如 Email 已存在）
