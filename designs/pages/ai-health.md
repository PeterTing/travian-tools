## 元件規格

### HealthScoreGauge

健康評分儀表盤。

```typescript
interface HealthScoreGaugeProps {
  score: number;
  previousScore?: number;
  lastChecked: Date;
}
```

**評分等級**:
- 90-100: 🟢 優秀
- 70-89: 🟡 良好
- 50-69: 🟠 需改進
- 0-49: 🔴 危險

---

### MetricCard

```typescript
interface MetricCardProps {

  summary: string;
```

```typescript
interface SuggestionCardProps {

  id: string;
  priority: 'high' | 'medium' | 'low';
  title: string;
  problem: string;
  risk?: string;
```

## 狀態管理

```typescript
interface HealthCheckState {
  selectedAccountId: string | null;
  currentResult: HealthCheckResult | null;
  isLoading: boolean;
  error: string | null;
  history: HealthCheckRecord[];
  expandedMetric: string | null;
}

interface HealthCheckResult {
  overallScore: number;
  previousScore?: number;
  checkedAt: Date;
  metrics: HealthMetric[];
  suggestions: Suggestion[];
  strengths: string[];
}

interface HealthMetric {
  id: string;
  name: string;
  icon: string;
  score: number;
  status: 'excellent' | 'good' | 'warning' | 'danger';
  summary: string;
  details: MetricDetail;
}
```

## API 整合

```typescript
// 執行健康檢查
POST /api/v1/strategy/health-check
Request: {
  account_id: string;
}
Response: HealthCheckResult

// 取得健康檢查歷史
GET /api/v1/strategy/health-check/history?account_id={id}
Response: HealthCheckRecord[]
```

## 響應式設計

### Desktop
- 指標卡片 3x2 網格
- 建議卡片完整顯示
- Modal 寬度 600px

### Tablet
- 指標卡片 2x3 網格
- 建議卡片垂直堆疊

### Mobile
- 指標卡片單欄
- 建議卡片可摺疊
- Modal 全螢幕
