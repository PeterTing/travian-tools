## 元件規格

### LoginForm

```typescript
interface LoginFormProps {
  onSubmit: (credentials: LoginCredentials) => Promise<void>;
  onGoogleLogin?: () => void;
  isLoading: boolean;
  error: string | null;
}

interface LoginCredentials {
  email: string;
  password: string;
  rememberMe: boolean;
}
```

## 表單驗證

| 欄位 | 驗證規則 | 錯誤訊息 |
|------|----------|----------|
| Email | 必填、Email 格式 | "請輸入有效的 Email" |
| 密碼 | 必填、最少 8 字元 | "密碼至少 8 個字元" |

## API 整合

```typescript
POST /api/v1/auth/login
Request: {
  email: string;
  password: string;
}
Response: {
  access_token: string;
  refresh_token: string;
  user: {
    id: string;
    email: string;
    name: string;
  }
}
```

---

## 流程

1. 用戶輸入 Email 和密碼
2. 點擊登入按鈕
3. 前端驗證表單
4. 發送 API 請求
5. 成功：儲存 Token，導向 /dashboard
6. 失敗：顯示錯誤訊息
