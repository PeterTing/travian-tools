## 元件規格

```typescript
interface BuildingGridProps {
  buildings: Building[];
  category: BuildingCategory;
  onSelect: (building: Building) => void;
}
```

### BuildingCard (預覽卡片)

```typescript
interface BuildingCardProps {
  building: Building;
  onClick: () => void;
}
```

**卡片內容**:
- 建築圖示
- 建築名稱
- 等級範圍
- 主要效果預覽

## API 整合

```typescript
// 取得建築列表
GET /api/v1/buildings
Response: Building[]

// 取得單一建築詳情
GET /api/v1/buildings/{building_id}
Response: BuildingDetail

// 取得特定等級數據
GET /api/v1/buildings/{building_id}/levels/{level}
Response: BuildingLevelData
```
