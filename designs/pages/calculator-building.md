## 元件規格

### BuildingSelector

建築選擇下拉選單。

```typescript
interface BuildingSelectorProps {
  value: Building | null;
  onChange: (building: Building) => void;
}
```

**功能**:
- 搜尋建築名稱（中/英）
- 按類別分組顯示
- 顯示建築圖示

---

### LevelRangeInput

等級範圍輸入。

```typescript
interface LevelRangeInputProps {
  startLevel: number;
  endLevel: number;
  maxLevel: number;
  onStartChange: (level: number) => void;
  onEndChange: (level: number) => void;
}
```

**驗證**:
- 起始等級 < 目標等級
- 等級範圍 0-20（或更高）

---

### MainBuildingSelector

本部等級快選。

```typescript
interface MainBuildingSelectorProps {
  value: number;
  onChange: (level: number) => void;
}
```

**快選項**: 1, 5, 10, 15, 20

---

### CalculationResult

計算結果顯示。

```typescript
interface CalculationResultProps {
  building: Building;
  startLevel: number;
  endLevel: number;
  totalCost: ResourceCost;
  totalTime: number;
  goldCost: number;
  populationIncrease: number;
  culturePointsIncrease: number;
  effectChange?: string;
}
```

---

### LevelBreakdownTable

逐級明細表格。

```typescript
interface LevelBreakdownTableProps {
  breakdown: LevelBreakdown[];
  expanded: boolean;
  onToggle: () => void;
}

interface LevelBreakdown {
  fromLevel: number;
  toLevel: number;
  cost: ResourceCost;
  time: number;
  cumulativeTime: number;
}
```
