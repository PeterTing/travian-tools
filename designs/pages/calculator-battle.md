## 元件規格

### TroopInput

部隊輸入元件。

```typescript
interface TroopInputProps {
  tribe: Tribe;
  troops: TroopUnit[];
  onChange: (troops: TroopUnit[]) => void;
  side: 'attacker' | 'defender';
}

interface TroopUnit {
  troopId: string;
  count: number;
}
```

**功能**:
- 顯示兵種選擇下拉
- 數量輸入框
- 新增/刪除兵種
- 顯示該兵種攻防數值

---

### WallSelector

城牆選擇器。

```typescript
interface WallSelectorProps {
  tribe: Tribe;
  level: number;
  onChange: (level: number) => void;
}
```

**顯示**:
- 城牆類型（根據種族）
- 等級選擇 (0-20)
- 防禦加成百分比

---

### PowerComparison

戰力對比視覺化。

```typescript
interface PowerComparisonProps {
  attackPower: number;
  defensePower: number;
}
```

**顯示**:
- 攻擊方總攻擊力
- 防守方總防禦力（含城牆加成）
- 比例條視覺化

---

### BattleResult

戰鬥結果顯示。

```typescript
interface BattleResultProps {
  winner: 'attacker' | 'defender';
  attackerLosses: TroopLoss[];
  defenderLosses: TroopLoss[];
  wallDamage: number;
  loot: ResourceLoot;
}

interface TroopLoss {
  troopId: string;
  before: number;
  after: number;
  lossRate: number;
}

interface ResourceLoot {
  capacity: number;
  wood: number;
  clay: number;
  iron: number;
  crop: number;
}
```

## 狀態管理

```typescript
interface BattleSimulatorState {
  mode: 'pvp' | 'pve';

  // 攻擊方
  attackerTribe: Tribe;
  attackerTroops: TroopUnit[];
  attackType: 'normal' | 'raid';
  attackerHero: boolean;
  attackerHeroBonus: number;

  // 防守方
  defenderTribe: Tribe;
  defenderTroops: TroopUnit[];
  wallLevel: number;
  defenderHero: boolean;
  defenderHeroBonus: number;

  // PvE 模式
  oasisType: string | null;
  wildAnimals: WildAnimal[];

  // 結果
  result: BattleResult | null;
  isSimulating: boolean;
}
```

## 說明 Modal

```
┌─────────────────────────────────────────────────────────────────────┐
│  戰鬥計算說明                                                   [X] │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  戰鬥公式                                                            │
│  ───────────────────────────────────────────────────────────────    │
│  攻擊力 = Σ(兵種攻擊力 × 數量) × (1 + 英雄加成)                     │
│  防禦力 = Σ(兵種防禦力 × 數量) × (1 + 城牆加成) × (1 + 英雄加成)    │
│                                                                     │
│  損失計算 (簡化)                                                     │
│  ───────────────────────────────────────────────────────────────    │
│  如果 攻擊力 > 防禦力:                                               │
│    攻擊方損失率 = (防禦力 / 攻擊力)²                                 │
│    防守方損失率 = 100%                                               │
│                                                                     │
│  如果 防禦力 > 攻擊力:                                               │
│    攻擊方損失率 = 100%                                               │
│    防守方損失率 = (攻擊力 / 防禦力)²                                 │
│                                                                     │
│  城牆加成                                                            │
│  ───────────────────────────────────────────────────────────────    │
│  │ 種族 │ 城牆類型 │ Lv1 加成 │ Lv10 加成 │ Lv20 加成 │             │
│  │ 羅馬 │ 城牆     │ +4%      │ +40%      │ +80%      │             │
│  │ 高盧 │ 木柵欄   │ +3%      │ +30%      │ +60%      │             │
│  │ 條頓 │ 土牆     │ +3.5%    │ +35%      │ +70%      │             │
│                                                                     │
│  注意事項                                                            │
│  ───────────────────────────────────────────────────────────────    │
│  • 模擬結果為近似值，實際戰鬥有隨機因素                               │
│  • 模擬誤差通常在 5% 以內                                            │
│  • 英雄戰鬥力、物品效果需手動輸入加成                                 │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```
