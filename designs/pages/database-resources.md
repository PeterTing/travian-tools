## 元件規格

### ResourceTypeSelector

```typescript
interface ResourceTypeSelectorProps {
  value: ResourceType;
  onChange: (type: ResourceType) => void;
}

type ResourceType = 'wood' | 'clay' | 'iron' | 'crop';
```

**樣式**:
```css
.resource-tab[data-type="wood"] { --resource-color: var(--resource-wood); }
.resource-tab[data-type="clay"] { --resource-color: var(--resource-clay); }
.resource-tab[data-type="iron"] { --resource-color: var(--resource-iron); }
.resource-tab[data-type="crop"] { --resource-color: var(--resource-crop); }

.resource-tab.active {
  background: hsl(var(--resource-color) / 0.1);
  border: 2px solid hsl(var(--resource-color));
}
```

---

### ResourceDataTable

```typescript
interface ResourceDataTableProps {
  resourceType: ResourceType;
  isCapital: boolean;
  onLevelClick?: (level: number) => void;
}

interface ResourceLevelData {
  level: number;
  production: number;
  cost: ResourceCost;
  buildTime: number; // seconds
  population: number;
  culturePoints: number;
  roi: number; // hours
}
```

**欄位說明**:
- 等級：0-20（首都可到更高）
- 產量/h：每小時產量
- 升級成本：4 種資源
- 建造時間：預設本部 Lv1
- 人口：佔用人口
- ROI：回本時間（小時）

---

### ResourceChart

產量趨勢圖表。

```typescript
interface ResourceChartProps {
  data: ResourceLevelData[];
  chartType: 'production' | 'cost' | 'roi';
  resourceType: ResourceType;
}
```

使用 Recharts 實作：
- 產量趨勢：LineChart
- 成本趨勢：BarChart (堆疊)
- ROI 趨勢：LineChart

## API 整合

```typescript
// 取得所有資源田數據
GET /api/v1/resources
Response: { [type: string]: ResourceLevelData[] }

// 取得特定類型資源田數據
GET /api/v1/resources/{type}
Response: ResourceLevelData[]

// 取得特定等級數據
GET /api/v1/resources/{type}/levels/{level}
Response: ResourceLevelData
```
