## 元件規格

### TribeTabSelector

種族標籤選擇器。

```typescript
interface TribeTabSelectorProps {
  selectedTribe: Tribe;
  onChange: (tribe: Tribe) => void;
}
```

**樣式**:
```css
.tribe-tab {
  padding: var(--spacing-2) var(--spacing-4);
  border-radius: var(--radius-md);
  cursor: pointer;
  transition: all 0.2s;
}

.tribe-tab[data-tribe="romans"] { --tribe-color: var(--tribe-romans); }
.tribe-tab[data-tribe="gauls"] { --tribe-color: var(--tribe-gauls); }
/* ... */

.tribe-tab.active {
  background: hsl(var(--tribe-color) / 0.1);
  border: 2px solid hsl(var(--tribe-color));
}
```

---

### TroopCard

兵種卡片。

```typescript
interface TroopCardProps {
  troop: Troop;
  onClick: () => void;
  selected?: boolean;
}
```

**卡片內容**:
- 兵種圖示
- 兵種名稱
- 攻擊/防禦（步/騎）
- 速度/糧耗

**樣式**:
```css
.troop-card {
  width: 160px;
  padding: var(--spacing-3);
  border-radius: var(--radius-lg);
  border: 1px solid var(--border);
}

.troop-card .stats {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: var(--spacing-1);
  font-size: var(--text-sm);
}
```

## API 整合

```typescript
// 取得所有兵種
GET /api/v1/troops
Response: Troop[]

// 取得特定種族兵種
GET /api/v1/troops/{tribe}
Response: Troop[]

// 取得單一兵種詳情
GET /api/v1/troops/{tribe}/{troop_id}
Response: TroopDetail

// 兵種比較
GET /api/v1/troops/compare?ids=t1,t2,t3
Response: TroopComparison
```

## 響應式設計

### Desktop
- 種族標籤水平排列
- 每行 4-5 個兵種卡片
- 比較面板在右側滑出

### Tablet
- 種族標籤可滑動
- 每行 3-4 個兵種卡片
- 比較面板在底部彈出

### Mobile
- 種族標籤可滑動
- 每行 2 個兵種卡片
- 比較面板全螢幕
